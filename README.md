# Sistema de Gestión de Certificados Digitales

## Descripción

Proyecto desarrollado como evidencia del programa Tecnólogo en Análisis y Desarrollo de Software del SENA.

El sistema permite la administración de usuarios, certificados digitales, solicitudes y bitácora mediante una API REST desarrollada en PHP y una interfaz web construida con HTML, CSS y JavaScript.

---

## Funcionalidades

- Gestión de usuarios.
- Inicio y cierre de sesión.
- Gestión de certificados.
- Gestión de solicitudes.
- Registro de bitácora.
- API REST para comunicación entre frontend y backend.

---

## Servicios Web

La API implementa los siguientes recursos:

| Endpoint | Descripción |
|----------|-------------|
| usuarios.php | Gestión de usuarios |
| certificados.php | Gestión de certificados |
| solicitudes.php | Gestión de solicitudes |
| bitacora.php | Registro de acciones |
| login.php | Inicio de sesión |
| logout.php | Cierre de sesión |
